# Como contribuir

Obrigado pelo interesse no Claude Island.

## Sugestões e problemas vão por issue

Este repositório não recebe pull requests de fora: a criação de PRs é restrita ao mantenedor.
Toda proposta de melhoria, relato de erro ou dúvida deve ser aberta como **issue**. O
mantenedor avalia cada uma e decide se e como ela entra.

Ao abrir uma issue, ajuda muito informar:

- o que você esperava e o que aconteceu;
- sistema operacional, versão do Node e do Claude Code;
- passos para reproduzir e, se for visual, uma captura de tela.

## Segurança

A ilha pode responder a pedidos de permissão do Claude Code, ou seja, aprovar a execução de
comandos. Se você encontrar uma falha que permita aprovar algo sem o usuário ver ou querer,
não abra uma issue pública com os detalhes: use o relato privado de vulnerabilidade do GitHub
(aba **Security** do repositório).
